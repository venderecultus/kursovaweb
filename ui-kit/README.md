# YARD UI Kit

Невелика браузерна бібліотека компонентів для магазину міського вінтажного одягу.

## Перегляд
- Відкрийте `index.html` у браузері.
- `foundations.html` містить спільні основи: палітру, типографіку й сітку.
- У папках компонентів `index.html` — навігація по станах; кожен інший HTML-файл показує один компонент в одному стані на порожньому полотні.
- Шрифт Manrope завантажується з Google Fonts; без мережі використовується системний резервний шрифт.

## Структура
- `button/` — default, hover, focus, pressed, disabled, loading.
- `text-field/` — empty, focus, filled, error, disabled.
- `checkbox/` — unchecked, checked, focus, disabled.
- `chip/` — default, selected, disabled.
- `product-card/` — product-card compositions for the assembled store; use price, badge, stock, swatch, navigation, title and description specimens for atomic Figma work.
- `size-option/` — default, selected, unavailable.
- `navigation/` — navigation link: default, hover, focus.
- `price/` — regular and sale price as atomic display elements.
- `badge/` — new and unavailable product badge.
- `stock-status/` — available, low-stock and unavailable text status.
- `swatch/` — color swatch: default, selected, unavailable.
- `storefront/` — окремі атомарні елементи магазину: повідомлення, посилання категорії, кнопка обраного, частини шляху, назва й опис товару, примітка про доставку.
- `cart/` — specimens окремих елементів кошика (рядок, кількість, видалення, сума до сплати й повернення); не сприймати повний екран кошика як компонент.
- `styles.css` — спільні дизайн-токени й стилі компонентів.
- `home.html` — зібраний адаптивний фрейм головної сторінки магазину YARD на основі цих компонентів і дизайн-токенів.
- `product.html` — адаптивна сторінка товару Canvas work jacket на основі картки товару з головної.
- `cart.html` — адаптивна сторінка кошика з товарами, зміною кількості та видаленням позицій.
- `catalog.html` і `contacts.html` — каталог колекції та сторінка контактів для курсової.

HTML UI Kit — браузерний референс, не готовий файл Figma. Зібрані сторінки магазину є демонстраційним прототипом; реальні оплата й обробка замовлень не підключені. Фото завантажуються із Unsplash (потрібне мережеве з'єднання); шрифт Manrope — із Google Fonts із системним резервним шрифтом.

Кожна specimen-сторінка має містити один атомарний компонент в одному стані на чистому полотні. Зібрані сторінки магазину перелічуються окремо та не є компонентами UI-kit.

## Перевірка вимог курсової

Сторінки магазину: `home.html`, `catalog.html`, `product.html`, `cart.html`, `contacts.html`. Навігація між ними доступна в шапці та/або контенті. Основні компоненти інтерфейсу (понад 20): промо-повідомлення, wordmark, навігація, посилання каталогу, посилання кошика, hero-зображення, заголовки, CTA-кнопка, посилання категорій, картка товару, фото товару, бейдж, ціна, кнопка обраного, рейтинг, відгук-посилання, опис, вибір кольору, вибір розміру, таблиця розмірів, кнопка додавання, статус наявності, інформація про доставку, accordion, хлібні крихти, лічильник кількості, видалення позиції, підсумок кошика, контактні посилання, підвал.

Ілюстрації — демонстраційні фотографії з Unsplash; вони показують одяг та його предметне оточення, не є фото власної продукції YARD. Наприклад, перший кадр каталогу показує куртку на вішаку, а не оливкову модель на людині.

Скріншоти для додатків: `screenshots/` містить desktop (1440 px, повна сторінка) і mobile (390 px) знімки всіх п’яти сторінок. UI kit можна переглядати локально відкривши `index.html`; інтерактивність і розрахунок кількостей кошика демонстраційні.
