# Скидос — головний екран

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер із цієї папки. Це HTML/CSS референс мобільного головного екрана, не нативна бібліотека Figma і не підключений до API продукт.

- `index.html` — екран головної сторінки для ширини iPhone.
- `styles.css` — адаптивні стилі та дизайн-токени.
- Шрифт Manrope завантажується з Google Fonts із системними fallback-шрифтами.
- Фото пропозицій завантажуються з Unsplash; мапа намальована CSS-ом.

Назви магазинів, пропозиції, ціни, відстані й кнопки — демонстраційні; перед використанням замініть реальними даними та діями.
