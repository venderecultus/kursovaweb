# YARD UI Kit

Browser component reference for the YARD React storefront. Start at `index.html` or open it from the running app at `/ui-kit/`. Each family index only links to states; each state file shows one specimen on a plain canvas. `foundations/` documents shared design tokens. This is an HTML reference for recreating components in Figma, not a Figma file. Design styles are in `ui-kit.css`; storefront tokens are in `../src/styles/tokens.css`.
