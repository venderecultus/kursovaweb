# Завдання 1 — Розробка сайту YARD та атомарного UI-kit

Відповідає **Завданню 2 «Розробка сайту»** у методичних вказівках; нумерація тут відповідає домовленості з користувачем.

## Мета
На основі наявного YARD UI-kit зібрати браузерний інтернет-магазин міського робочого одягу щонайменше з п'ятьма сторінками й окрему бібліотеку найдрібніших UI-компонентів/станів, зручну для відтворення у Figma.

## Вимоги
- Не менше 5 сторінок: головна, каталог, товар, кошик, контакти; всі доступні через навігацію. Додаткова сторінка «Про бренд» — за потреби.
- Фото/відеоматеріали, зовнішні гіперпосилання на інші ресурси, назва YARD на головній і сторінка контактів.
- Не менше 20 різних компонентів на сайті; перелічити їх у README/висновках.
- Кожна сторінка сайту має відповідати стилю YARD, використовувати спільні токени та працювати на мобільному екрані.
- UI-kit ведеться окремо від зібраного магазину за `.guide/Creating a UI Kit in HTML.md`.
- У component index розміщати лише навігацію; у кожному state-файлі — рівно один атомарний компонент на чистому полотні. Спільні основи мають власну сторінку.
- Стани (hover, focus, selected, disabled, error, loading тощо) створювати лише там, де вони мають сенс для конкретного компонента.
- Складені блоки ділити: не створювати specimen-и типу «картка товару з усіма діями» чи «панель покупки». Текст, ціна, бейдж, наявність, кнопка, селектор, статус — окремі самостійні компоненти, де доречно.
- Використовувати семантичні HTML-теги, пов'язані labels, alt-тексти, видимий клавіатурний focus і текстові ознаки помилок/недоступності.

## Приймання
1. У браузері відкриваються всі п'ять сторінок, внутрішні переходи працюють.
2. На індексі UI-kit є посилання на foundations і кожне сімейство; сімейні індекси ведуть до всіх наявних станів.
3. На state-сторінках присутній один компонент, без шапки/підвалу/сусідніх зразків.
4. Немає зламаних шляхів до CSS/зображень, обрізання контенту на вузькому екрані.
5. README пояснює запуск, структуру, зовнішні залежності та що HTML є референсом для Figma, а не файлом Figma.
6. Зроблено скриншоти сторінок для додатків курсової.

## Примітка про основу
Використовується `ui-kit/` (YARD: міський вінтажний/робочий одяг, палітра paper/ink/olive/acid/rust, Manrope, наявні сторінки home/product/cart та атомарні заготовки компонентів). Не змінювати незалежну демо-сторінку повітряних кульок у корені проєкту.
